# StudySync Frontend

Frontend-first scaffold for a Student Productivity & Performance Analytics system using:

- HTML + Bootstrap 5
- Custom CSS
- Vanilla JavaScript
- Chart.js

## Run locally

From project root:

```bash
python3 -m http.server 8000
```

Then open:

- `http://localhost:8000/index.html`
- `http://localhost:8000/pages/dashboard/dashboard.html`
